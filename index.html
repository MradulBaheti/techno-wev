Linux Web Server Testing

The following commands can be used by an administrator to verify that the web server is functioning correctly.

$ systemctl status httpd

$ systemctl is-active httpd

$ curl http://localhost

$ ss -tulnp | grep :80

$ firewall-cmd --list-all

$ ls -lah /var/www/html

Web Server Test Checklist

Basic Connectivity

  • Server has a valid IP address.
  • Apache service is installed.
  • Apache service is running.
  • Port 80 is listening.
  • Firewall allows HTTP traffic.
  • Security group allows inbound HTTP traffic.
  • Client can reach the server IP.
  • index.html exists in the document root.
  • Browser can load the webpage.

How a Web Request Works

When a user enters a website address into a browser, several steps occur before the webpage is displayed.

  1. The browser receives the requested URL.
  2. DNS resolves the domain name into an IP address.
  3. The browser establishes a network connection to the server.
  4. The client sends an HTTP request to port 80 or HTTPS request to port 443.
  5. The web server receives the request.
  6. Apache searches the configured document root.
  7. The server returns the requested HTML document.
  8. The browser renders the HTML, CSS, and other resources.
